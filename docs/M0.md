# Running the M0 probes

Run from the repository root with Node 22+ and pnpm 12.18.0. Supply secrets in the process environment. Do not paste them into chat. Each probe prints PASS/FAIL and appends a dated result to DECISIONS.md; FAIL for missing environment means the integration was not tested.

1. `pnpm exec tsx scripts/m0-memwal.ts` — requires MEMWAL_ACCOUNT_ID and MEMWAL_KEY_CHECKER. Writes one labelled sample record, persists idempotency/job state under ignored `.local/`, waits up to 55 seconds, then recalls the exact blob. Rerun to resume; do not delete state after a timeout.
2. `pnpm exec tsx scripts/m0-delegates.ts` — additionally requires distinct MEMWAL_KEY_TELEGRAM and MEMWAL_KEY_MCP. All three read the first probe's blob.
3. `pnpm exec tsx scripts/m0-namespaces.ts` — enumerates namespaces and memories using has_more and next_cursor, checks namespace acceptance and expiry field.
4. `pnpm exec tsx scripts/m0-tatum-grpc.ts` — requires TATUM_API_KEY, WATCH_ADDRESS, M0_SUI_NAME (known active name), M0_OBJECT_ID (known existing object); optional M0_COIN_TYPE defaults to SUI. Four sequential reads, spaced 1.1 seconds apart. This verifies fields are returned, not that the supplied subject is owned by the user. Native TLS transport, x-api-key metadata. Do not run alongside another Tatum process before the shared production limiter exists.
5. `pnpm exec tsx scripts/m0-tatum-graphql.ts` — requires TATUM_API_KEY and TATUM_SUI_GRAPHQL copied from the Tatum dashboard. No guessed endpoint and no automatic public fallback. Initial checkpoint connectivity probe only; historical filters and retention remain a separate corpus gate.
6. `pnpm exec tsx scripts/m0-groq.ts` — requires GROQ_API_KEY and GROQ_MODEL selected from the console. Sends only synthetic text; checks schema and extracted values.

These scripts do not establish the whole M0 gate by themselves. Vercel gRPC, credits per call, superseded recall behavior, gentle write-rate measurement, historical GraphQL coverage, and real account network/expiry proof still require live evidence. Read-only SDK inspection is not a mainnet pass. No public publishing or spending is authorized by running these local checks.
